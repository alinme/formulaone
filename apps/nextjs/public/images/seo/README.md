# SEO Images

Replace these placeholder images with your actual assets:

| File | Dimensions | Use |
|------|------------|-----|
| `og-default.png` | 1200×630 | Open Graph default (Facebook, LinkedIn, etc.) |
| `og-home.png` | 1200×630 | Home page specific OG image |
| `twitter-card.png` | 1200×628 | Twitter/X summary_large_image card |
| `twitter-header.png` | 1500×500 | Twitter/X header/banner |
| `blog-featured-default.png` | 1200×630 | Default blog post featured image |
| `logo-og.png` | 1200×630 | Logo/fallback for OG sharing |

## Blog post images

For individual posts, add: `blog/{slug}-featured.png` (e.g. `blog/monaco-gp-tickets-featured.png`)
